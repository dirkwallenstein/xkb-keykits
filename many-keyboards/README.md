### Keykits (many-keyboards)

This is another demonstration using a more comprehensive configuration. You can
choose from three different keyboard models provided by 'Username'. The
'usersymbols' toolkit is always appended to the symbols and therefore overrides
the language layouts you choose in the desktop menus.

It shows an inclusion hierarchy in keycodes, how to add the different
components to desktop menus, and how to register and dispatch custom
keyboard models via rules.
